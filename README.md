# QGYM - Enterprise Multi-Branch Gym Management System

نظام إدارة الجيم المركزي المتكامل لإدارة عدة فروع بقاعدة بيانات وهوية عميل مركزية موحدة.

---

## 🌟 الميزات الرئيسية للنظام

1. **قاعدة بيانات مركزية واحدة (Single Centralized Database)**:
   - العميل له سجل واحد فقط في النظام مهما تعددت الفروع التي يزورها (`Customer ID: GYM-XXXXXX`).
   - تحديد الفرع الأساسي للعميل (`Home Branch`) مع حفظ تاريخ الانتقالات (`Customer Branch History`).
2. **محرك صلاحيات الدخول بين الفروع (Multi-Branch Access Engine)**:
   - اشتراك شامل الفروع (`UNLIMITED`): مسموح بالدخول لجميع فروع النظام.
   - اشتراك فرع واحد فقط (`HOME_BRANCH_ONLY`): مسموح بالدخول لفرعه الأساسي فقط، ومرفوض في الفروع الأخرى مع إظهار السبب بدقة.
   - اشتراك فروع محددة (`SELECTED_BRANCHES`): مسموح بالدخول للفروع المحددة في باقته فقط.
3. **بوابة تسجيل الحضور اللحظية (Live Check-In Terminal)**:
   - التحقق الفوري بواسطة كود العميل، رقم الهاتف، الباركود، أو الـ QR.
   - إشعارات مرئية وصوتية (أخضر للمصرح لهم / أحمر للمرفوضين مع ذكر السبب).
4. **إدارة الخزينة والتقفيل اليومي (Cashier & Daily Closing)**:
   - فتح ورديات خزينة (`Cash Sessions`).
   - حساب فوري للنقدية الفعلية مقابل المتوقعة (`Opening + Cash In - Cash Out = Expected Cash`).
   - احتساب العجز أو الزيادة بالمليم وطباعة ملخص التقفيل.
5. **المدفوعات والمصروفات**:
   - طرق دفع متعددة: كاش، فيزا (POS)، إنستاباي (InstaPay)، فودافون كاش.
   - تبويب المصروفات حسب الفروع والتصنيفات (نظافة، صيانة، مرافق، رواتب).
6. **ملف العميل الشامل (360° Customer Profile)**:
   - نظرة عامة، الاشتراكات السابقة والحالية، سجل الحضور عبر كل الفروع.
   - سجل الإيصالات والمدفوعات.
   - قياسات InBody مع رسم بياني لمتابعة الوزن ونسبة الدهون عبر الزمن.
   - جدول تمارين تدريبي مخصص يوم بيوم (تمارين، مجموعات، تكرارات، أوزان).
   - سجل انتقالات العميل بين الفروع السابقة والحالية.
7. **لوحة تحكم وتحليلات مقارنة (Multi-Branch Matrix & Comparison)**:
   - مقارنة الإيرادات، المصروفات، صافي الأرباح، ونسب الإشغال بين الفروع.
   - رسم بياني لساعات الذروة (Peak Hours).
   - تصدير التقارير إلى ملفات Excel / CSV بضغطة زر.
8. **الأمان وسجل التدقيق (Audit Trail)**:
   - توثيق وتسجيل كل العمليات الحساسة في `activity_logs`.
   - تحكم صارم بالصلاحيات على مستوى الدور والفرع (`RBAC & BBAC`).

## 🚀 تشغيل المشروع

### 1. تثبيت الحزم (إن لم تكن مثبتة):
```bash
npm install
```

### 2. تهيئة قاعدة البيانات والبيانات التجريبية:
```bash
npm run db:push
npm run db:seed
```

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 4. تشغيل الاختبارات الآلية للتحقق من كافة القواعد:
```bash
npx tsx scripts/verify-system.ts
```
